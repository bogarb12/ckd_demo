LINE Bot Script Generator

สร้างสคริปต์บอทสำหรับแชทกลุ่มผู้ป่วยเบาหวาน

วิธีใช้งาน LINE Bot

ขั้นตอนการตั้งค่า:

  1. เลือกประเภทสคริปต์ที่ต้องการด้านล่าง
  2. ตั้งค่าตัวเลือกตามต้องการ (ช่วงเวลา, ข้อความ)
  3. กดปุ่ม "สร้างสคริปต์"
  4. คัดลอกสคริปต์ที่ได้ไปวางใน Google Apps Script
  5. ตั้ง Trigger ตามที่ระบุในสคริปต์

การเชื่อมต่อ LINE:

  1. สร้าง LINE Notify Token ที่ notify-bot.line.me หรือสร้าง LINE Messaging API Channel ที่ developers.line.biz
  2. นำ Token มาใส่ในช่อง "LINE Token" ด้านล่าง
  3. เชิญบอทเข้ากลุ่ม LINE ของสมาชิก
